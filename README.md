# Cranach Catalog Finder

The 2026 Cranach catalog and search index are included. Products that have
completed visual setup are ready for consistent client packages; unfinished
sections are clearly identified inside Catalog Setup.

## Download for Mac

[**Download Cranach Catalog Finder for Mac**](https://github.com/Freddough/cranach-catalog-finder-releases/releases/download/v1.0.3/Cranach-Catalog-Finder-1.0.3-arm64.dmg)

Version 1.0.3 works on Apple-silicon Macs with macOS 13 or newer.

## Install in 3 steps

1. When the download finishes, open it from your browser's **Downloads** button.
2. In the window that opens, double-click **Cranach Catalog Finder**.
3. Click **Install and Open**. The app finishes setup and opens the catalog.

After this first installation, the app can offer future updates itself.

### System files

The ZIP, release manifest, appcast, and `.delta` files are used by the app's
secure update system. You do not need to download or open them.
